ADMIN LOGIN (GITHUB TOKEN)

Anyone can look at this page, but only someone with a token that can edit the workfor repo can hire, promote or fire. The token is saved only in this browser and is sent only to GitHub. To make one: GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token → Repository access: only workfor → Permissions: Issues: Read and write. Never share it, and never put it in a file or a chat.
